# glo

A simple build/issue/agent management system

## Initialization

If glo has already been set up in your repo, open shell in repo root and run

1. `git submodule init && git submodule update`

## Installation

To install in your repo, open shell in repo root and run:

1. `git submodule add https://github.com/ejconlon/glo.git submodules/glo`
2. `./submodules/glo/bootstrap.sh`
